# Biology MM v1.0 Live Capability & Readiness Matrix

**Scope & Status Definitions**
Every capability below is classified strictly as one of four statuses based on direct code inspection and executed verification in `foundation/`:

- **`supported`**: Implemented, covered by passing deterministic tests in the active 57-suite runner (`julia/test/run_all.jl`), `pytest` suites, or formal proof builds (`lake build`, `coqc`), with documented tolerances and invariants.
- **`experimental`**: Implemented and passes smoke/prototype or synthetic checks, but lacks full production equilibration, full format coverage, or end-to-end physical convergence.
- **`refused`**: Explicitly rejected by typed contract gates (`ResolvedSystemError`, `UnsupportedCapability`, `MissingBoxDerivative`, `UnsupportedGeometry`, `ChemistryError`, `ConstraintIncompatibilityError`, `MissingVirialError`, `ArgumentError`, or `force_model_supported == false`).
- **`untested`**: Not exercised by current `foundation/` tests or CI workflows.
